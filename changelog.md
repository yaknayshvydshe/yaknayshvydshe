# Changelog

## [v0.2](#) - Jun 27, 2024

### Adicionado
- Redirecionamento da folha de rosto para `mobile.html` se o usuário estiver em um dispositivo móvel (Android, iPhone, iPad, tablets).
  - Quando um usuário clica no botão com a classe `trigger`, ele será redirecionado para `mobile.html` se estiver em um dispositivo móvel.
    - Criados arquivos `mobile.css`, `mobile.scss` e `mobile.js` para o suporte a dispositivos móveis.

### Planejamento 

- Colaborar com design de novos negócios.

## [v0.1](https://github.com/yaknayshvydshe/yaknayshvydshe/commit/1c5c2831d4c26fcf83b258d23e10bb81aaa6d6a3) - Jun 26, 2024

### Atualização
- Atualização em raíz de indexação:
  - O arquivo `index.html` não estava carregando corretamente porque estava localizado dentro da pasta `dist`. Foi movido para a raíz do projeto para garantir que seja indexado corretamente pelos servidores e mecanismos de busca.

### Ajuste
- Ajuste no tamanho e texto das letras na folha de rosto.
  - A classe `portfolio_home__title` teve seu campo limitado para garantir melhor legibilidade e consistência visual na folha de rosto.

### Alteração
- Alteração nas dimensões das imagens em dispositivos móveis da marca:
  - O logotipo da marca foi alterado, mas essa mudança foi revertida para manter a consistência visual e de marca.

### Melhoria
- Implementação de melhorias no SEO para aumentar a visibilidade nos mecanismos de busca.

### Planejamento
- Próxima correção planejada: Implementação de um layout compatível para dispositivos móveis.
